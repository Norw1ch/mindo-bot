# Мои задачи — Telegram Mini App

Личное приложение внутри Telegram: задачи, заметки, привычки, расходы и списки в одном месте.
Открывается кнопкой «Задачи» в чате с ботом. Оформление в стиле iOS, светлая и тёмная тема
подстраиваются под Telegram.

Работает только для владельца: бот отвечает одному Telegram ID, а данные лежат
в облаке Telegram у твоего аккаунта.

## Что умеет

Внизу шесть вкладок. Язык интерфейса — русский, українська или English (Главная → Настройки).

**Главная** открывается при запуске:
- Поиск по всему: задачи, заметки, привычки, расходы (по категории, комментарию и сумме) и списки.
- Карточка «Сегодня»: привычки, задачи в работе, расходы за сегодня и прогресс привычек.
- Быстрые кнопки «Задача», «Заметка», «Расход» открывают форму добавления прямо здесь.
- Плитки разделов с короткой сводкой и «Новый раздел», который создаёт раздел в «Задачах».
- «Настройки»: язык и резервная копия.

**Задачи**
- Разделы: создать, переименовать, удалить (кнопкой или свайпом влево).
- Задача: заголовок и описание — правятся прямо на экране, кнопка «Готово» справа сверху.
- Статусы ⚪ Not started / ◐ In progress / ⚫ Done, фильтры в разделе.
- Срок (сегодня, завтра, через неделю или календарь) и блок «Сегодня» на главном экране, экран «Все сроки».
- Повтор: каждый день, по будням, каждую неделю, месяц, год. После Done задача переезжает на следующую дату.
- Чеклист внутри задачи, прогресс «2/5» в списке.
- Поиск по заголовкам, описаниям и пунктам чеклистов.
- «Выполненные» — по разделам, можно вернуть в работу.

**Заметки** — заголовок и текст, закрепление сверху, поиск, копирование текста.

**Привычки** — отметка за день, серия дней подряд, лучшая серия, календарь месяца.
График: каждый день или выбранные дни недели (например, Пн, Ср, Пт) — серия считает только их.

**Расходы** — в гривнах: сумма, категория, комментарий, дата (по умолчанию сегодня, можно выбрать
другой день в календаре). Итог за период: этот месяц, прошлый, 7 дней, вчера, сегодня, всё время
или свои даты. Разбивка по категориям, свои категории.

**Списки** — покупки, вещи в поездку: быстрое добавление по Enter, отмеченное уезжает вниз,
«Снять все отметки», «Удалить отмеченные».

**Резервная копия** (Главная → Настройки) — скопировать все данные текстом
или скачать файлом, восстановить из копии.

Длинные списки показываются по 8 штук на странице. Свайп влево по строке — удаление.

## Как это устроено

```
Telegram ──▶ бот (bot.py, работает на твоём ПК)
   │           └─ на /start присылает кнопку «Открыть задачи» и ставит кнопку меню «Задачи»
   │
   └──▶ приложение (папка docs/, опубликовано на GitHub Pages)
               └─ данные хранит в облаке Telegram (CloudStorage) твоего аккаунта
```

- **Приложение** — обычная веб-страница из папки `docs`. GitHub Pages бесплатно публикует её
  по адресу https://norw1ch.github.io/mindo-bot/
- **Бот** нужен только чтобы ответить на `/start` и поставить кнопку меню.
  Кнопка меню «Задачи» остаётся и при выключенном боте — приложение открывается всегда.
- **Данные** не попадают ни на GitHub, ни на компьютер — они в облаке Telegram.
  Облако даёт 1024 записи по 4096 символов. Каждая задача занимает одну запись,
  а заметки, списки, привычки и расходы упакованы по несколько в одну запись — так места
  хватает надолго. Сколько занято, видно на экране «Резервная копия».

## Структура проекта

```
mindo-bot/
  bot.py              — бот: кнопка «Открыть задачи» и кнопка меню, отвечает только владельцу
  config.py           — читает настройки из .env
  requirements.txt    — библиотеки Python (aiogram, python-dotenv)
  .env.example        — образец настроек с пояснениями
  .env                — твои настройки (токен, ID, адрес) — НЕ попадает в Git
  docs/
    index.html        — страница приложения
    style.css         — оформление
    js/
      core.js         — основа: Telegram, хранилище, даты, мелкие помощники
      lang.js         — языки: переводы на украинский и английский, склонения
      ui.js           — общий интерфейс: вкладки, переходы, окна, свайпы, правка на месте
      plans.js        — вкладка «Задачи»
      notes.js        — вкладка «Заметки»
      lists.js        — вкладка «Списки»
      habits.js       — вкладка «Привычки»
      money.js        — вкладка «Расходы»
      backup.js       — резервная копия
      settings.js     — экран «Настройки»
      home.js         — вкладка «Главная»: сводка, быстрые кнопки, плитки, поиск по всему
      main.js         — список вкладок и запуск
```

## Установка (Windows, PowerShell)

Нужны установленные **Python 3.12+** и **Git**. Все команды выполняются в папке проекта:

```powershell
cd C:\Cloude\mindo-bot
```

1. Создать виртуальное окружение — отдельную папку `.venv` с библиотеками только для этого проекта:

   ```powershell
   python -m venv .venv
   ```

2. Установить библиотеки:

   ```powershell
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

3. Создать файл настроек из образца:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Открыть `.env` в VS Code и заполнить:

   | Строка | Что вписать | Где взять |
   |---|---|---|
   | `BOT_TOKEN` | токен бота | в Telegram написать **@BotFather** → `/newbot` (или `/mybots` для существующего) |
   | `OWNER_ID` | твой Telegram ID, только цифры | написать **@userinfobot** |
   | `WEBAPP_URL` | адрес приложения | `https://norw1ch.github.io/mindo-bot/` |

   Файл `.env` содержит секрет (токен). Никому его не отправляй и не добавляй в Git —
   он уже указан в `.gitignore`.

## Запуск бота

```powershell
.venv\Scripts\python bot.py
```

Должна появиться строка `Run polling for bot @...` — бот работает.
Остановить: **Ctrl+C**.

Проверка: в Telegram отправь боту `/start` — придёт «Мои задачи» с кнопкой «Открыть задачи».
Слева от поля ввода появится кнопка «Задачи».

Если вместо этого видишь «Не заполнен файл .env…» — проверь шаг 4 установки.

## Как обновить приложение

Приложение обновляется через GitHub — бота перезапускать не нужно.

1. Изменить файлы в `docs/`. Новый текст на экране пишется по-русски внутри `t('…')`,
   а его перевод добавляется в `docs/js/lang.js`: без перевода покажется русский.
2. В `docs/index.html` увеличить число после `?v=` **во всех строках** (у всех файлов одинаковое,
   например `?v=28` → `?v=29`). Иначе Telegram может показывать старую копию.
3. Сохранить и отправить изменения:

   ```powershell
   git add -A
   git commit -m "Что изменилось"
   git push
   ```

4. Через минуту закрыть и заново открыть приложение в Telegram.

Если менялся `bot.py` — остановить бота (Ctrl+C) и запустить снова.

## Резервная копия

Все данные живут только в облаке Telegram, поэтому время от времени сохраняй копию:

1. «Главная» → «Настройки» → «Резервная копия» → **«Скопировать копию»**.
2. Открой в Telegram «Избранное» и вставь текст — копия хранится там.

Восстановить: тот же экран → «Восстановить из текста» → вставь сохранённый текст.
Текущие данные будут **заменены** копией (приложение спросит подтверждение).

«Скачать файлом» работает на компьютере и обычно на Android; в Telegram на iPhone —
пользуйся копированием.

## Посмотреть приложение на компьютере

```powershell
start docs\index.html
```

Откроется в браузере. Вне Telegram данные хранятся в самом браузере (отдельно от телефона) —
удобно посмотреть внешний вид, не трогая настоящие данные.

## Ограничения

- Облако Telegram — 1024 записи на пользователя: это примерно **900 задач** плюс остальные вкладки.
- Задача целиком (заголовок, описание, чеклист) — до ~4000 символов; описание — до 3000.
- Напоминаний нет: для них боту нужно работать круглосуточно на сервере.
- Нужен Telegram с поддержкой Mini Apps версии 6.9 и новее (любая актуальная версия).
- Бот в чате отвечает по-русски: язык из настроек действует только внутри приложения.
