# Мои планы — Telegram Mini App

Личное приложение для планов внутри Telegram. Планы разложены по разделам и имеют статусы
⚪ Not started, ◐ In progress, ⚫ Done. Выполненные собираются на отдельном экране «Выполненные».

Работает только для владельца: бот отвечает одному Telegram ID, а данные хранятся
в облаке Telegram у твоего аккаунта.

## Что умеет

- Разделы: создать, переименовать, удалить (с подтверждением). Удаление ещё и свайпом влево.
- Планы: заголовок и необязательное описание; изменить, удалить (кнопкой или свайпом).
- Статусы переключаются в карточке плана.
- Фильтры в разделе: Все (⚪ и ◐) / Not started / In progress / Done.
- «Выполненные»: все планы со статусом Done, сгруппированы по разделам, можно «↺ Вернуть в работу».
- Длинные списки показываются по 8 штук на странице.
- Стиль iOS, светлая и тёмная тема (подстраивается под Telegram), плавные анимации.

## Как это устроено

```
Telegram ──▶ бот (bot.py, работает на твоём ПК)
   │           └─ на /start присылает кнопку «Открыть планы» и ставит кнопку меню «Планы»
   │
   └──▶ приложение (папка docs/, опубликовано на GitHub Pages)
               └─ данные хранит в облаке Telegram (CloudStorage) твоего аккаунта
```

- **Приложение** — обычная веб-страница: `docs/index.html`, `docs/style.css`, `docs/app.js`.
  GitHub Pages бесплатно публикует папку `docs` по адресу
  https://norw1ch.github.io/mindo-bot/
- **Бот** нужен только чтобы ответить на `/start` и поставить кнопку меню.
  Кнопка меню «Планы» остаётся и при выключенном боте, так что приложение открывается всегда.
- **Данные** не попадают ни на GitHub, ни на компьютер — они в облаке Telegram.

## Структура проекта

```
mindo-bot/
  bot.py            — бот: кнопка «Открыть планы» и кнопка меню, отвечает только владельцу
  config.py         — читает настройки из .env
  requirements.txt  — библиотеки Python (aiogram, python-dotenv)
  .env.example      — образец настроек с пояснениями
  .env              — твои настройки (токен, ID, адрес) — НЕ попадает в Git
  docs/
    index.html      — страница приложения
    style.css       — оформление
    app.js          — вся логика приложения
```

## Установка (Windows, PowerShell)

Нужны установленные **Python 3.12+** и **Git**. Все команды выполняются в папке проекта:

```powershell
cd C:\Cloude\mindo-bot
```

1. Создать виртуальное окружение — отдельную папку `.venv` с библиотеками только для этого проекта:

   ```powershell
   python -m venv .venv
   ```

2. Установить библиотеки:

   ```powershell
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

3. Создать файл настроек из образца:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Открыть `.env` в VS Code и заполнить:

   | Строка | Что вписать | Где взять |
   |---|---|---|
   | `BOT_TOKEN` | токен бота | в Telegram написать **@BotFather** → `/newbot` (или `/mybots` для существующего) |
   | `OWNER_ID` | твой Telegram ID, только цифры | написать **@userinfobot** |
   | `WEBAPP_URL` | адрес приложения | `https://norw1ch.github.io/mindo-bot/` |

   Файл `.env` содержит секрет (токен). Никому его не отправляй и не добавляй в Git —
   он уже указан в `.gitignore`.

## Запуск бота

```powershell
.venv\Scripts\python bot.py
```

Должна появиться строка `Run polling for bot @...` — бот работает.
Остановить: **Ctrl+C**.

Проверка: в Telegram отправь боту `/start` — придёт «Мои планы» с кнопкой «Открыть планы».
Слева от поля ввода появится кнопка «Планы».

Если вместо этого видишь «Не заполнен файл .env…» — проверь шаг 4 установки.

## Как обновить приложение

Приложение обновляется через GitHub — бота перезапускать не нужно.

1. Изменить файлы в `docs/`.
2. В `docs/index.html` увеличить число после `?v=` у изменённого файла
   (например, `app.js?v=14` → `app.js?v=15`). Иначе Telegram может показывать старую копию.
3. Сохранить и отправить изменения:

   ```powershell
   git add -A
   git commit -m "Что изменилось"
   git push
   ```

4. Через минуту закрыть и заново открыть приложение в Telegram.

Если менялся `bot.py` — остановить бота (Ctrl+C) и запустить снова.

## Посмотреть приложение на компьютере

```powershell
start docs\index.html
```

Откроется в браузере. Вне Telegram данные хранятся в самом браузере (отдельно от телефона) —
это удобно, чтобы посмотреть внешний вид, не трогая настоящие планы.

## Ограничения

- Облако Telegram вмещает до 1024 записей на пользователя: это примерно **1000 планов**
  (каждый план — отдельная запись, плюс одна запись со списком разделов).
- Заголовок плана — до 80 символов, описание — до 3000, название раздела — до 50.
- Нужен Telegram с поддержкой Mini Apps версии 6.9 и новее (любая актуальная версия).
